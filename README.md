## 🧠 Patient Condition Classification Using Drug Reviews

An end-to-end NLP application that predicts medical conditions from patient drug reviews using an interpretable **TF-IDF + Linear SVM** pipeline.

### Highlights

- 96.16% Test Accuracy
- 94.60% Macro F1 Score
- TF-IDF + Linear SVM
- Streamlit Deployment
- Sentiment Analysis
- Interactive AI Prediction Interface

### Live Demo
